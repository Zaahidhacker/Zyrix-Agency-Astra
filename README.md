# Rivora showcase
A lightweight static landing page for the Rivora weather and community safety prototype.

Design read: landing page for Sri Lankan citizens and hackathon reviewers, with a trust-first dark-tech language leaning toward native CSS, Poppins, one cyan accent and restrained motion.

Features covered: multi-source weather, WBGT-informed Heat Stress Intelligence, safer route planning, photo-supported community reports with voting, daily quiz leaderboard, and Rivi product story.

This is intentionally a showcase site, not a live weather service.
